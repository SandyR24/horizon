# HORIZON

Prototype de site pédagogique pour intégrer des activités Wordwall.

## Installation sur GitHub Pages
1. Ajouter `index.html` à la racine du dépôt.
2. Ouvrir Settings > Pages.
3. Dans Build and deployment, sélectionner Deploy from a branch, branche `main`, dossier `/(root)`.
4. Enregistrer et attendre la publication.

## Important
Ceci est une **démonstration uniquement** : données enregistrées dans le localStorage du navigateur, sans authentification, sans base de données ni récupération des scores Wordwall. Ne pas y enregistrer de données personnelles d'élèves. L'espace enseignant n'est pas protégé. Les URL des iframes sont limitées à Wordwall.
